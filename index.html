Perguntas frequentes

Este site está conectado ao MyCompiler?

Não. Ele reproduz, de forma interativa, os dados e a estrutura do script SQL validado. As compras simuladas ficam apenas nesta página e somem ao recarregar. O banco original permanece intacto.

As compras e os pagamentos são reais?

Não. É uma atividade educacional, sem cobrança, login, envio de dados nem emissão de pedidos reais.

Onde está o código SQL completo?

O script validado está disponível no link do MyCompiler acima.
